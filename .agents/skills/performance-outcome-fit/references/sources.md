# Public source map

Accessed 2026-08-04.

## Primary and first-party sources

1. Lou Adler Group, [Performance-based Hiring](https://www.louadlergroup.com/about-us/performance-based-hiring/)
   - End-to-end method; define work as challenges and deliverables; compare accomplishments; present a career opportunity.
2. Lou Adler, [Performance-based Hiring is Win-Win Hiring](https://www.louadlergroup.com/performance-based-hiring-is-win-win-hiring/)
   - Judge success at the first-year anniversary, not the start date; use high-touch processes for scarce talent.
3. Lou Adler, [Spot High Achievers with These Sherlock Clues](https://www.louadlergroup.com/spot-high-achievers-with-these-sherlock-clues/)
   - Doing versus having; Most Significant Accomplishment; fact finding, pattern recognition, and comparable evidence.
4. Lou Adler, [Using AI to Create Win-Win Hiring Careers](https://www.louadlergroup.com/using-ai-to-create-win-win-hiring-careers/)
   - Critiques transactional AI acceleration; argues for relationship-based, value-focused recruiting.
5. Lou Adler, [Using ChatGPT to Conduct Job Analysis](https://www.louadlergroup.com/using-chatgpt-to-conduct-job-analysis/)
   - Behavioral assessment without job analysis is vulnerable to perception and bias.
6. Lou Adler Group, [Win-Win Hiring workshop](https://www.louadlergroup.com/training/performance-based-hiring-for-recruiters/)
   - Public outline covering EVP, career moves, motivation, fit, evidence-based closing, and sequencing.

## Interpretation note

These sources describe a commercial methodology. Preserve their useful operational principles while treating performance claims and proprietary scorecards as claims requiring independent validation.
