# GET-22: from a captured person to a connected world

## Outcome and scope

The user rejected the first delivery's aesthetics and missing aha moment.
Make the future product mechanism tangible: Action Button from an existing
platform, Agent research across authorized sources, one person across identities,
and discovery of a relevant connection to the user's existing world.
This is a website and synthetic interactive vision, not implementation of global
device capture, new account connectors, real identity merging or autonomous search.
Preserve multilingual navigation, pricing truth and existing working demos.

## D0: product invariant

Visitor: a person whose work depends on people, initially an independent recruiter.
Tension: they encounter someone in IM but cannot see the context and shared history
scattered across profiles, conversations and meetings. They should feel the surprise
of recognizing a connection that was already in their world. Press the Action Button
and inspect why the newly visible path exists. Distinctive mechanism: capture in
place → reconcile person context → find a source-backed path to a current intent.
It is an intended integrated experience, not a claim of an exclusive shipped feature.

The previous delivery passed functional gates but failed the user's design judgment.
Backtrack from its evidence-review-first D1 rather than polishing that composition.

## D1: two theorems

A, the connected world: one small action turns scattered fragments into a living
person, then opens the surrounding relationships. Spatial grammar: an open field
with a tactile Action Button and a continuous shared person anchor. Content:
recognizable fragments, integration, then one unexpected bridge. Signature mechanic:
fragments converge, source identities reconcile, one path visibly illuminates.
Anti-reference: a static network wallpaper or central card with explanatory copy.

B, the shortest human path: start with an intent and reveal who could help it move.
Spatial grammar: large goal prompt followed by a traversable horizontal path.
Content: intent, people, path explanation. Signature: changing the intent changes
which source-backed path is shown. Anti-reference: a generic AI prompt box.

## D2: architectures for A

A1: center-led opening with fragments and Action Button → expanding relationship
space → dark cross-platform capture interlude → living-person editorial composition
→ compact FAQ/access. Slow/open → active convergence → discovery → quiet invitation.
A2: a pinned full-screen film owns the first scroll journey before normal sections.
Reject A2 for scroll ownership, delayed access and mobile/reduced-motion friction.
Retain B as a challenger; choose after rendered first-view and mid-page comparison.

References: Family (tactile interactions and shape continuity), Cosmos (a personal
spatial collection), mymind (capture without filing), and Read AI Ada (context
retrieval across surfaces). Inspect mechanisms, not copy or entire identities.
The UI database's kinetic brutalism/pink/Inter recommendation is not adopted;
its immersive structure, skip control and motion fallback are relevant.

## Evidence and completion

Use a fully synthetic Maya/Alex case with existing concept portraits. A social
profile, public project and saved note resolve to one synthetic identity via an
explicit shared handle, not avatar similarity. A source-backed former-colleague
edge is distinct from an unconfirmed possible introduction. Remove support and
the path disappears. No external source access or contact writes occur.

Functional gates and design judgments remain separate. Test image loading,
keyboard, language changes, fast replay/cancel, stale timers, source removal,
mobile and reduced motion. Capture initial/convergence/person/path states and a
short screen sequence where possible. The user's taste correction is authoritative;
passing tests does not establish an aha moment or user preference.
