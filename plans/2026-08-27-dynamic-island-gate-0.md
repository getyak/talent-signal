# Dynamic Island Gate 0 visual validation

## Outcome

Produce three fairly comparable, platform-faithful high-fidelity stimuli for
the Talent Signal Synthetic Research Showcase, then record an evidence-backed
Gate 0 decision before any ActivityKit product implementation starts.

The comparison must let an independent reviewer judge whether a recruiter can
understand one canonical `running + observe` state within five seconds without
mistaking public-page research for candidate contact, an external write, a
finished result, a timer, or determinate progress.

## Boundary

In scope:

- the corrected 17 / 42 / 73 visual directions;
- minimal, compact leading/trailing, expanded, and Lock Screen surfaces;
- the shared semantics `RESEARCH`, `Reading approved pages`, `You can leave`,
  `Public sources only`, and `Open status`;
- platform geometry, privacy, accessibility risk, logo-off ownability, and
  comparison fairness;
- a dated internal review artifact with a GO or NO-GO result.

Out of scope:

- production SwiftUI or ActivityKit implementation;
- APNs, push-to-start, update-token storage, exact task readback, or backend
  research continuity;
- claims about Always-On, physical-device behavior, background delivery, or
  recruiter preference;
- candidate names, companies, conversation text, percentages, timers, ETAs,
  or any consequential action from the system surface;
- choosing a visual winner before every candidate passes the comprehension and
  safety gates.

review and would make any fidelity claim circular.

## Design read

- **Surface:** iOS capture / Today companion projected into Live Activity
  system surfaces.
- **Audience:** independent recruiters and boutique search operators moving
  between desktop research and iPhone status review.
- **User question:** what is happening, may I leave, and do I need to act?
- **Character:** restrained, reliable, editorial, and recognizably Talent
  Signal without glass, glow, decorative loading, or AI theater.
- **Attention hierarchy:** execution fact, evidence boundary, attention
  handoff, then one safe route back to status.
- **Canonical object:** one synthetic research task; the Live Activity is only
  a privacy-safe projection and carries no execution authority.

## Chosen approach

1. Recover the corrected round-two board or a rendered preview exported from
   it. Treat that artifact as the visual source of truth for 17 / 42 / 73.
2. Create three independent high-fidelity stimuli with identical canvas,
   system bounds, canonical state, semantic inventory, typography scale, and
   exposure time. Vary only the intended structural direction.
3. Review the three stimuli without direction names. First test platform shape,
   single-state consistency, privacy, and action semantics; only then compare
   ownability and visual character.
4. Record the result under `docs/evaluations/` with the exact stimuli, reviewer
   observations, inferred conclusions, unresolved device evidence, and a
   Gate 0 GO or NO-GO.
5. Prepare the eight-recruiter cold-read package only after Gate 0 is GO.

Rejected alternatives:

- Generating from the prose summary alone would invent the missing source and
  make the comparison impossible to audit.
- Starting the Debug showcase now would spend implementation effort before the
  visual contract has passed its explicit gate.
- Using simulated black rectangles as proof would not establish Dynamic Island
  or Lock Screen fidelity.
- Combining running and completed states in one stimulus would reintroduce the
  first-round comparison failure.

## Milestones

1. **In progress — recover the source (local recovery exhausted)**
   - obtain the corrected `.excalidraw` file, its latest PNG/PDF export, or both;
   - verify that 17, 42, and 73 each contain minimal, compact, expanded, and
     Lock Screen surfaces with the corrected shared semantics;
   - preserve the received source unchanged and record its provenance.
   - next authority required: the user supplies the source/export, or explicitly
     changes the task from continuation review to a fresh three-direction
     exploration.
2. **Pending — high-fidelity stimuli**
   - create three independent renders from the recovered source;
   - use the approved Held Interval asset rather than redrawing the mark;
   - keep system geometry, semantic inventory, state, and scale identical;
   - disclose that these are design stimuli, not captured ActivityKit UI.
3. **Pending — internal Gate 0 review**
   - inspect minimal and compact geometry against actual platform regions;
   - test logo-off distinction, grayscale meaning, reduced-motion intent,
     Dynamic Type risk, truncation, and privacy;
   - block on any implied progress, completion, candidate contact, external
     write, retry authority, or PII exposure;
   - record GO or NO-GO without selecting a winner on aesthetics alone.
4. **Pending — cold-read package**
   - randomize display order and hide direction names and rationales;
   - preserve raw five-second answers separately from team interpretation;
   - require at least 6/8 participants to explain the stage and attention need;
   - treat any external-action or privacy misunderstanding as a redesign
     blocker, not a vote to average away.

## Completion proof

- The three stimuli are inspectable, independently rendered artifacts derived
  from the recovered round-two source.
- All candidates use the same canonical state, text inventory, system bounds,
  scale, and exposure conditions.
- An internal review names platform, semantic, privacy, accessibility, and
  comparison findings with exact visual evidence.
- Gate 0 has one explicit GO or NO-GO decision and does not claim recruiter
  preference, real ActivityKit behavior, Always-On behavior, or background
  delivery.
- If Gate 0 is GO, the cold-read package is ready without changing the tested
  stimuli; if NO-GO, the review identifies the smallest structural correction.

## Replanning signals

Re-plan if the recovered board is older than the documented corrections, if it
cannot distinguish 17 / 42 / 73 without explanatory labels, if current Apple
system geometry invalidates the fixed reference bounds, or if the user chooses
to abandon source recovery and explicitly authorizes a fresh three-direction
exploration instead of a continuation review.
