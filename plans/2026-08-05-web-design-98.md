# Web design 98

> Historical and superseded. The user rejected this result as polished but
> generic. Its functional checks remain useful, but the self-authored 98 score
> must not be reused as evidence of design quality. The active correction is
> `plans/2026-08-05-root-redline-design.md`.

## Outcome

Rebuild the public Talent Signal narrative into a distinctive, quiet,
evidence-first experience whose motion explains how conversation evidence
becomes reviewed relationship state and one controlled next action.

## Boundary

In scope: public home page composition, responsive behavior, motion language,
interactive proof, accessibility, and visual verification.

Out of scope: changing product truth, authentication behavior, workspace data
contracts, or enabling any external write.

## Current evidence

- The existing site has the correct warm-neutral/vermilion foundation and
  strong interactive proof.
- The page rhythm still reads as a sequence of similarly revealed sections.
- Motion is mostly one generic upward reveal and does not yet create a
  continuous evidence-to-action narrative.
- Browser navigation through the connected Chrome surface currently times out;
  the local Next.js server itself is healthy.

## Approach

1. Preserve the real interactive candidate brief and governed-state language.
2. Tighten the hero into one viewport and make the evidence loop visible before
   the user interacts.
3. Introduce a restrained page-level progress motif and section-specific reveal
   choreography, with complete reduced-motion behavior.
4. Recompose repeated section rhythms without adding decorative feature cards.
5. Verify desktop/mobile, keyboard, reduced motion, lint, typecheck, tests,
   build, and docs.

## Completion evidence

- Direct desktop and mobile screenshots of the current local page.
- Interactive brief changes recommendation without losing source context.
- No horizontal overflow at 320px and 1440px.
- Keyboard-visible focus and reduced-motion static equivalent.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, and
  `pnpm docs:check` pass.
