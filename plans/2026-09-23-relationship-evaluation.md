# Relationship conversation evaluation

## Outcome and boundary

Create an IMStage project and a corresponding Eval Case Studio library of
natural synthetic WeChat/WhatsApp conversations. Exercise actual Talent Signal
contact, calendar, multimodal and public-person research paths, improve
confirmed failures, and verify the real product surface. The twelve public
authors are discussion subjects, never purported private correspondents.
Synthetic expectations are proposed; human labels remain pending. No external
invitation or calendar insertion is authorized by a model-generated draft.

## Verification boundaries

The synthetic PostgreSQL/API/Next environment is isolated from the user's
running production service. Browser upload could not be exercised because the
existing extension denies local file access; admission used the authenticated
product API and UI verification began from the persisted Session. No permission
was bypassed. Calendar export bytes were generated by the actual UI; no OS
calendar import occurred. Human semantic review remains pending. Social
channels exist in the adapter but real provider acceptance in this task uses
web sources. Native iOS/macOS builds and production deployment are outside the
verified surface and are not represented as passed.
