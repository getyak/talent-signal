# Momentum Experience V2 baseline

Status: MX-00 exit gate met; release and comparative claims remain withheld
Goal: MX-00 only
Data classification: synthetic only

This bundle freezes the current Talent Signal baseline and the definition of a
comparative win before any Momentum Experience V2 redesign result is observed.
It does not change product behavior and does not claim physical-device latency,
manual VoiceOver completion, recruiter preference, field effectiveness, or a
direct Ailoha comparison without the corresponding evidence.

The frozen user journey is the governed iOS path from one intentional source to
inspectable evidence, a separate fact decision, a separately reviewable next
move, and a truthful local outcome or recovery state. No test in this bundle is
authorized to send a message, create a meeting, write Contacts or ATS state, or
use private candidate content.

## Result

- The Release simulator build and Debug synthetic review build have stable
  identities; all six focused iOS UI tests passed.
- The nineteen required scenarios are fully accounted for: four direct passes,
  five observed failures, nine explicit gaps, and one human study not run.
- The deterministic P0 suite passed all twelve safety checks, but every case
  remains `needs_review`; no release approval is claimed.
- Twenty-three measures name start event, stop event, device, evidence,
  aggregation, target where applicable, and current proof status.
- The comparative win rule is frozen before redesign results. It is
  conjunctive: a blocker, missing comparator, or missing destination proof
  produces `no_claim`.
- Ailoha direct comparison is unavailable because no authorized frozen build
  or account was available. The manual comparator is a frozen synthetic
  protocol whose representative-participant run is pending.

The product-adjudicator packet validly abstains pending independent specialist,
physical-device, VoiceOver, Calendar destination, Ailoha, and field evidence.
This is a completed baseline contract, not a product release or a claim that
Talent Signal is already better.
