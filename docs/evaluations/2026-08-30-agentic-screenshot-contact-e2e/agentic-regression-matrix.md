# Screenshot-to-contact Agentic regression matrix

## Purpose

This matrix consolidates independent evidence-safety and recruiter-workflow
case design for the authenticated desktop Web loop. Every fixture must be
synthetic and authorized. A passing model response is not sufficient proof:
each case names the canonical state or rendered result that must be read back.

The Agent may analyze, coordinate, compile, and propose. It may not bind an
ambiguous identity, confirm a fact, or execute an external effect on the
recruiter's behalf.

## Three next agentic-browser scenarios

1. **AG-EDIT-01 — corrected OCR through refreshed compiled readback.** This is
   the best full-loop proof that reviewed text, rather than the original model
   output, owns downstream evidence.
2. **AG-RETRY-01 — applied-but-response-lost reconciliation.** Use deterministic
   response interception and read canonical counts/IDs before and after retry.
3. **AG-LIFE-01 — source authority revocation/deletion.** Prove invalidation
   propagates through fact, action, Wiki, citation, Agent answer, and history.
