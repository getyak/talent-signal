# 0015: Private evaluation and delegated prompt improvement

- Status: accepted direction; implementation proof is tracked separately
- Date: 2026-09-07

## Decision

The owner's [GET-11](https://linear.app/getyak/issue/GET-11) scope permits complete
business content in the existing private Opik instance and bounded optimizer.
Real corrections may become source-linked frozen development cases without a
second per-case privacy approval or mandatory synthetic reconstruction. This
extends the synthetic-only experiment boundary in ADRs 0011 and 0012. Their
deterministic scenarios, quality-state isolation and business-action boundaries
remain valid.

Codex may review and approve exact prompt candidates within the owner's
delegated release scope. Candidate generators and model judges cannot approve
releases, change evaluation criteria or obtain final holdout material. The
owner supplies monetary limits and environment/exposure scope; missing limits
do not become authorization by default. Release review does not confer contact,
calendar, message or confirmed-fact write authority.

Formal prompts continue to ship with code under ADR 0013. A selected candidate
becomes a reviewable source change and application release. Running tasks keep
their captured snapshots; publishing an Opik label does not activate a prompt.

## Rationale

Reconstructing every real failure as a synthetic scenario discards context and
can hide the original error. Complete authorized inputs make reproducibility
possible, while source ownership, time, deletion and distinct judgment origins
preserve the meaning of that evidence. Automated candidate search is useful
only when it can consume the same task path as the product and retain failed
trials, unresolved outcomes and cost.

Independent final validation and exact release review prevent a higher average
score from hiding identity, permission or other critical regressions. Atomic
reservations before provider requests keep concurrency, retries and unknown
billed outcomes inside the delegated resource boundary.

## Consequences and reconsideration

The first quality claim is limited to relationship Ask text. Media can be
stored and observed under the authorized policy, but text evaluation does not
certify screenshot recognition or every Agent workflow. Feedback is a claim
about an answer, not human gold or a causal hiring-outcome label.

Credentials remain configuration, never task content. Final holdouts stay
outside the generator's input and execution authority even though business
content is otherwise permitted. Source removal invalidates derivatives and
late replay cannot restore them. Local results remain authoritative when Opik
is unavailable; a successful SDK call is insufficient without readback.

Reconsider task scope, algorithm or platform when measured failures show that
the shared product adapter, independent verification or existing private
instance cannot support the next useful improvement.
