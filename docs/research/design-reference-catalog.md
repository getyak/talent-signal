# Design reference catalog

This is the quick-retrieval home for products with a reusable visual,
interaction, or product-shape judgment relevant to Talent Signal. Each entry
states what the product is, links to a primary product source, and explains in
one sentence why the design is worth studying and where the borrowing should
stop.

The catalog is research, not canonical product truth. Detailed reasoning stays
in the linked study; stable Talent Signal decisions belong in the
[Design system](../design-system.md).

## Entry rule

Add a reference only when it demonstrates a specific, reusable design
mechanism. Prefer an official product or documentation link, describe the
mechanism instead of saying only that it "looks good," and name both the useful
lesson and the boundary against imitation.
