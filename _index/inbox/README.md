# Wiki inbox

Start new human or LLM-authored articles here. Inbox files may be incomplete,
but they must still distinguish sourced facts, interpretations, open questions,
and proposed decisions.

Before publishing:

- look for an existing page with the same concept;
- attach or link repository-safe source records;
- remove copied private or copyrighted material;
- give the page one durable subject and a precise title;
- move it to `_index/pages/` using `templates/page.md`.
