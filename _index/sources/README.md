# Source records

Store one source in one subdirectory or Markdown record. A source record should
capture:

- title and original URL or repository path;
- author or owner;
- publication and access dates when known;
- usage rights or confidentiality;
- why the source matters;
- a short excerpt or screenshot description;
- which note or page uses it.

Repository-safe product screenshots may be stored beside their record. Never
commit real candidate screenshots, private conversations, credentials, access
tokens, or full third-party articles without permission.
